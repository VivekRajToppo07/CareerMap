# CareerMap 🧭

**CareerMap** is an AI-powered pocket career counselor designed to act as a 24/7 personalized campus placement cell[cite: 1]. Built specifically to address the hiring realities and salary bands of Tier-2/3 regional college graduates, it helps turn a generic tech degree into real job traction[cite: 1]. 

Instead of relying on generic online advice, CareerMap runs a quick, conversational assessment to profile a B.Tech graduate’s core engineering skills—whether that's a strong foundation in Java, proficiency in SQL, or an understanding of complex data structures—and outputs highly targeted, localized career paths.

## 🚀 Key Features

* **Conversational Profiling:** A 10-15 question LangGraph AI assessment that accurately maps an individual's strengths and interests[cite: 1].
* **Targeted Job Paths:** Generates the top 3 tailored career trajectories specifically tuned for regional job markets[cite: 1].
* **Zero-Cost Upskilling Roadmaps:** Curates step-by-step learning guides using strictly free online resources[cite: 1].
* **Live Job Hunting:** Integrated web search dynamically pulls active, entry-level job listings related to the suggested paths.

## 🛠️ Tech Stack

* **AI Orchestration:** LangGraph & LangChain 
* **LLM:** Groq API (llama-3.3-70b-versatile) for high-speed, low-cost reasoning
* **Frontend:** Next.js (Deployed on Vercel)
* **Backend:** FastAPI (Deployed on Replit)
* **Database & Auth:** Supabase (PostgreSQL)

## 🎯 The Problem We're Solving

Talented graduates from non-metro campuses often apply to jobs randomly due to a lack of clear career direction[cite: 1]. Massive EdTech platforms are usually metro-focused and expensive to access[cite: 1]. CareerMap bridges this gap by acting as an affordable, hyper-localized guide that stops the cycle of zero-traction applications[cite: 1].

## 📈 Key Metrics Tracked

* **Completion Rate:** Percentage of users finishing the 10-15 question AI assessment[cite: 1].
* **Engagement Rate:** Tracking users saving or acting on a suggested path[cite: 1].
* **Conversion:** Monitoring the 3-5% target for paid tier upgrades (99 INR/month)[cite: 1].
